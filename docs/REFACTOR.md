# 2026-11-14 修复与接口适配

基于 `05def2c`。修改保留 `st_voice` 设置、`extra.st_voice` 配音表、人物、参考音频库和各提供商的声音记录。

## 核心修复

- 切聊天、编辑消息或停止后，旧分析结果不再写入新聊天；同消息同时分析共用一次请求，强制重分析会取消旧任务。
- 配音表缺行、重复行或格式错误会提示重试，不会存成假的全旁白结果。合法全旁白仍可保存。
- 播放和导出固定本次接口与声音；缓存区分接口地址、参数、输出格式和参考文字稿。
- 停止会取消导出和预取；跳过末句会停止真实音频，末句的上一句操作可以重播；认证失败不再继续下一条消息。
- 普通短句和含数字的叙述不再误判为状态栏；跨加粗节点的引号仍可识别；隐藏文字跳过。
- 关闭插件会停止播放；页面和 iframe 正文变化时更新句子标记；播放结束释放音频地址。
- 导出也遵守缓存上限，音频拼接前后检查取消，切聊天后不再下载旧内容。
- 设置试听共用一个可取消的播放器；重复试听复用结果，关窗和切页会停止、取消并释放音频地址。下载按实际音频格式命名。
- 切换 OpenAI 预设会提示清理不兼容的音色，保留人物名字和其他提供商记录；设置页使用统一字段组件，按钮支持键盘操作。

音频缓存使用完整合成条件作新标识，不依赖仅在安全页面提供的 Web Crypto；手机从局域网 HTTP 打开也可使用。旧缓存仍能在设置页查看或删除，新播放不会复用可能混用过的旧标识；第一次重播可能需要重新合成。

## 后端续查

- 同一句、同一声音同时预取时只合成一次；浏览器缓存不可用时，本轮也复用结果。
- 合成很慢时，上一句 / 下一句不再等待被跳过的请求；取消时也不再等待缓存写入。
- 消息末尾合成失败会停止连播；旧的“继续播放”操作迟到报错，不会停止新队列。
- 引号内的斜体仍算对白，独立斜体动作仍保留原分类；带时间标签的完整叙述不再整段判为状态。
- 不同角色使用相同聊天名、相同文本时，各自的自动播放仍能触发。
- Fish 适配器在读取参考文件前固定参考参数，消除试听等待期间改文字稿造成的串线。
- HTTP 200 返回纯文本或 JSON 时会报错，不再把错误内容当音频缓存；删除未使用的缓存统计函数。

## 刷新后的配音表与标记

刷新会恢复页面上所有已分析回复的标记，不再只处理最新一条。新配音表同时保存正文对应关系：已识别的状态行更新时间、增减或换位置，不会触发正文重新分析；正文或目标语言真正变化时仍会失效。手动修改说话人后，也会更新对应关系并保存。

旧格式的配音表在正文校验通过时仍可沿用。旧格式没有保存逐句正文，若其校验已因状态变化失效，需要重新分析一次，之后使用新格式。iframe 正文晚于页面加载出现时也会恢复标记。

## 接口范围

| 接口 | 本次行为 |
| --- | --- |
| OpenAI 兼容 | 接受域名、带 `/v1` 的地址或完整合成地址，保留中转路径前缀；密钥可留空；模型与音色可手填；支持 MP3、WAV、Opus、AAC、FLAC |
| Fish 兼容 | 域名默认使用 `/compat/v1/audio/speech`，明确填到 `/v1` 或完整合成路径时尊重该路径；参考音频仍通过官方接口 |
| Fish 原生 | 新增 `/v1/tts`，模型放请求头，支持声音 ID 和 MessagePack 二进制参考音频；参考音频发给所填服务 |
| Groq 预设 | 更新为 Orpheus English、对应声音与 WAV；已保存的旧配置不自动改写，可重新选择预设更新 |
| MiniMax、豆包、ElevenLabs、Azure、Gemini、Edge | 保留现有酒馆后端路由及密钥库；新增提供商继续使用独立适配文件和声明式配置项 |

格式是否可用以所选服务和浏览器为准；不提供裸 PCM，因为播放组件需要带音频容器的数据。浏览器直连的接口还需允许跨域。酒馆当前连接的分析服务如果不支持取消底层请求，本插件会及时结束等待并丢弃迟到结果，但无法承诺厂商停止计费。

## 全量复查

- 重新分析失败保留旧结果；聊天保存失败后，下次使用会补存已完成的分析，不重复调用模型。切换聊天、停止时关闭旧句子的播放弹窗。
- 角色没有单独配声音时，翻译使用实际默认声音的语言；有单独声音且选择“跟正文一样”的人物不继承默认翻译。设置了默认语言的旧配音表需要重分析一次以采用新规则，未设置默认语言的旧记录继续兼容。
- 修改朗读筛选、声音和语言后同步刷新标记；Fish 账号音色修改语言或删除时同步人物和默认声音。
- iframe 正文延迟出现时再自动播放；停止后不会突然补播。嵌套 iframe 可以点句播放，页面从浏览器缓存恢复后继续监测正文。
- 播放或导出遇到损坏音频时清掉该段缓存，允许重试；缓存事务取消时结束等待，其他页面升级数据库时释放旧连接。
- Edge 声音列表改用服务端要求的 GET；Fish 自建无认证服务可以不填密钥；ElevenLabs 未选声音时直接提示。移除 MiniMax 未使用的 Group ID 设置和 Edge 未使用的 rate 参数。
- 试听在离开页面时取消；窗口不重复堆叠，Tab 焦点留在窗口内，关闭后恢复焦点。字段补上可读名称，装饰图标不参与朗读；浏览器禁止保存悬浮球位置时仍能完成拖动。
- 确认框以纯文本显示音色名称，避免名称中的 HTML 被执行。保留原有确认、取消流程。

没有新增运行时依赖，播放和导出继续共用播放器、缓存和合成配置；模型、界面零件和确认框修复均放在已有公共入口。

## 官方协议依据

- [OpenAI Speech API](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)：请求字段、格式，以及 `tts-1` / `tts-1-hd` 不支持 `instructions`。兼容厂商的模型列表和生命周期独立于 OpenAI。
- [Fish 原生 TTS](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech) 与 [参考音频说明](https://docs.fish.audio/features/text-to-speech)：原生路径、模型请求头、JSON 与 MessagePack。
- [Groq 停用记录](https://console.groq.com/docs/deprecations) 与 [Orpheus 文档](https://console.groq.com/docs/text-to-speech/orpheus)：PlayAI 已停用，替代模型只输出 WAV。
- [Web Crypto 的安全页面限制](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/subtle)：缓存标识改为直接使用完整条件，避免依赖 `crypto.subtle`。
- [Edge 服务端插件源码](https://github.com/SillyTavern/SillyTavern-EdgeTTS-Plugin/blob/main/src/index.ts)：`GET /list`、`POST /generate` 和响应音频类型。

本地回归使用模拟服务，没有调用真实付费接口或替换正在运行的酒馆插件。运行方法见 [开发说明](DEVELOPMENT.md)。
