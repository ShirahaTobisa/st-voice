# st-voice（酒馆语音）

SillyTavern（酒馆）的第三方扩展，把 AI 回复读出来。两种模式：

- **朗读**：整条回复用一个声音读，可以只读引号里的对白、跳过括号和星号动作。
- **角色配音**：先让模型分出每一句是谁说的、什么语气，然后每个人物用自己的声音说台词，旁白可读可不读。

第一版只接 Fish Audio，提供商做成了可插拔的（`src/providers/`），以后加别家只需要补一个文件。不做背景音乐和音效。

## 安装

1. 酒馆 → 扩展 → 安装扩展，填 `https://github.com/ShirahaTobisa/st-voice`；或者把整个文件夹放到 `public/scripts/extensions/third-party/st-voice`。
2. 刷新页面。入口在聊天框左下角的 ≡ 菜单里（「语音设置」），不占扩展面板。

## 用法

- 每条消息的操作栏里多了两个按钮：**喇叭** 播放这条消息（播放中变成停止），**列表** 看预览。
- 聊天页上有个**悬浮球**，能拖动，位置记在本机。点开是播放面板：切朗读 / 角色配音、播放最新回复、停止、分析（角色配音模式才有，重新分析最新回复并打开预览）、预览、进设置；播放时显示正在念的是谁、念到第几句，正文里对应的句子会高亮。
- 预览：朗读模式能看到哪些句子会被读、哪些被跳过；角色配音模式能改每句的说话人和语气，改完直接播放，也能让模型重新分析。
- 设置窗：悬浮球面板里的齿轮，或左下角 ≡ 菜单 → 语音设置。左侧导航分四页，手机上变成顶部一排；总开关在「基本」页最上面。

### 设置项

| 页 | 内容 |
| --- | --- |
| 基本 | 模式；回复结束自动播放、双击消息播放、显示悬浮球；只读对白、不读括号、不读星号动作、配音模式也读旁白、读自己的台词；语速；角色配音的分析用哪个模型（酒馆当前连接，或自己填一个 OpenAI 兼容接口：地址 + 密钥 + 从接口拉模型列表，请求由酒馆后端转发）、回复结束自动分析 |
| Fish Audio | 密钥、模型（免费版 / 付费版）、默认声音。选声音有三个来源：从 Fish 公共声音库搜（能试听）、自己克隆过的音色（能删）、用音频文件克隆新音色。克隆有两种：「用参考音频」把音频存在酒馆里，合成时随请求发给 Fish，不占账号名额；「建成 Fish 音色」在账号里建私有音色（占名额，可多段音频，之后合成不用再传） |
| 配音表 | 按角色卡存：人物名字对应的声音。分析过的人物会自动加进来，没配声音的用默认声音；加一行「旁白」可以给这张卡单独指定朗读/旁白的声音 |
| 缓存 | 合成过的音频存在浏览器里，同一句重听不再花钱；能看占用、一键清空 |

### Fish Audio 说明

- 密钥在 fish.audio 的 API Keys 页面创建，只存在酒馆的扩展设置里。
- 免费模型可能把请求内容留存用于训练，私密内容建议用付费模型。
- 声音直接用公共声音库里公开声音的 ID，不占你账号的收藏名额。
- 参考音频存在酒馆的用户文件里（`data/<用户>/user/files/st-voice-*.mp3`），合成时取出来转成 base64 放在请求的 `provider.options.fish-audio.references` 里；换掉或删掉后没人用的文件会自动删。建成 Fish 音色走 Fish 的建模接口，音频存在 Fish 那边，能存几个看你的套餐。两种都建议 10 到 30 秒、干净无背景音乐，附文字稿发音更准。
- 语气按 Fish S2 的写法放在句首方括号里，所以分析出的语气是英文短语。

## 原理

- 读的是页面上显示出来的正文（正则替换之后的），自动跳过代码块、折叠块、表格、图片、按钮和隐藏内容。
- 句子分几类：对白（引号里的）、动作（星号里的）、括号、叙述、状态。状态行是「好感 80」「TIME 09:00」这种短的带数字无标点的行，再把挨着它们的短行、夹在它们中间的行一起算进去，这样状态栏、变量面板整块都会被认出来，不读、不分析、预览里也不显示。
- 角色配音时把编号后的句子交给模型，附上已知人物、用户名字和角色设定的前几百字，要它按配音导演的规则返回每句的说话人和语气：引号归人物；心理活动、内心独白、没加引号但明显是人物在说或在想的话也归人物（语气轻一些）；第三人称叙述和描写归旁白；代称换本名；分不清就旁白；语气写英文短语。结果存在消息的 `extra.st_voice` 里，文字没变就不会再问模型。
- 合成走 Fish Audio 的 OpenAI 兼容接口，浏览器直连，不经过酒馆后端。

## 目录

| 文件 | 用途 |
| --- | --- |
| `index.js` | 入口：设置初始化、消息按钮、播放流程、预览、事件 |
| `src/text.js` | 从消息里取句子、句子高亮 |
| `src/analyze.js` | 角色配音的分析提示词和结果解析 |
| `src/player.js` | 播放队列、预取、缓存 |
| `src/cache.js` | IndexedDB 音频缓存 |
| `src/settings.js` | 设置窗的四页：基本、Fish Audio、配音表、缓存 |
| `src/widget.js` | 悬浮球和播放面板 |
| `src/ui.js` | 界面零件：窗口、卡片、字段、开关、滑条、按钮、列表行 |
| `src/providers/fish.js` | Fish Audio 合成和声音库搜索 |

## 开发

本地测试时把项目目录用目录链接（junction）挂到酒馆的 `public/scripts/extensions/third-party/st-voice`，改完刷新页面即可。
